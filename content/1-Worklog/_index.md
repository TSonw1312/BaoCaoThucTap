Typically, and as a standard, a worklog is carried out over about 3 months (throughout the internship period) with weekly contents as follows:

**Week 1:** Introduction to cloud computing concepts, AWS Global Infrastructure, account initialization, and AWS CLI setup.

**Week 2:** Managing identity and access with AWS IAM, applying the principle of least privilege, and configuring AWS Budgets for cost monitoring.

**Week 3:** Studying Amazon VPC networking, including subnets, routing, security groups, network ACLs, and basic network security configuration.

**Week 4:** Exploring AWS storage services, implementing Amazon S3 static website hosting, and learning about Amazon EBS and Amazon EFS.

**Week 5:** Provisioning Amazon EC2 instances, managing Amazon RDS databases, and understanding Auto Scaling and Elastic Load Balancing.

**Week 6:** Building a Serverless backend using AWS Lambda and Amazon API Gateway, and implementing RESTful APIs.

**Week 7:** Learning Amazon DynamoDB, implementing user authentication with Amazon Cognito, and managing application identities.

**Week 8:** Integrating the frontend with the Serverless backend, studying AWS monitoring and security services, and defining the AWS Serverless Hybrid architecture.

**Week 9:** Migrating the Express backend to AWS Lambda, implementing authentication with Amazon Cognito and Amazon SES, synchronizing user profiles with MongoDB, and securing APIs using API Gateway JWT Authorizer.

**Week 10:** Implementing secure file uploads with Amazon S3 Presigned URLs, developing asynchronous Word document processing using AWS Lambda, and integrating parsed data into MongoDB.

**Week 11:** Implementing asynchronous exam grading using Amazon SQS, AWS Lambda Grading Worker, Dead Letter Queue (DLQ), and Amazon CloudWatch monitoring.

**Week 12:** Deploying the frontend to AWS Amplify Hosting, configuring Route 53 and CORS settings, performing end-to-end testing, reviewing security configurations, and completing the project proposal and workshop documentation.
