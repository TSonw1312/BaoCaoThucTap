This section will list and introduce the blogs you have posted to [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj). For example:

###  [Blog 1 - AUTOMATING CROSS-ACCOUNT DATA REFRESH FOR AMAZON RDS MULTI-AZ DB CLUSTERS](3.1-Blog1/)
This blog guides you on how to build a serverless pipeline using AWS Lambda, Step Functions, and EventBridge to automate the entire data refresh process for Amazon RDS Multi-AZ DB Clusters between separate AWS accounts while maintaining end-to-end security via AWS KMS.

###  [Blog 2 - EXPLORING AMAZON AURORA DSQL – A NEW DATABASE SOLUTION ON AWS](3.2-Blog2/)
This blog explores Amazon Aurora DSQL, a newly introduced serverless, distributed SQL database compatible with PostgreSQL. It covers key highlights such as automatic scaling without sharding, high availability with Active-Active architecture, and zero infrastructure management.

###  [Blog 3 - OPTIMIZING EC2 COSTS BY ANALYZING CAPACITY RESERVATIONS WITH AMAZON ATHENA](3.3-Blog3/)
This blog discusses maximizing Amazon EC2 Capacity Reservation utilization using Amazon Athena. It explains how to export hourly capacity data to Amazon S3 in Parquet format and run standard SQL queries to proactively detect underutilized reservations and optimize enterprise-scale infrastructure costs.
